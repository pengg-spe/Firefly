| 食物类别   | 食物选择                                                                                                                                                                                                            | 食用理由                                                                                                |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 油性冷水鱼类 | **沙丁鱼、鲭鱼、鳀鱼**、野外捕获的**鲑鱼和鲱鱼，金枪鱼**                                                                                                                                                                                | ω-3脂肪酸含量最高，还有各种其他营养物质                                                                               |
| 贝类     | **牡蛎，花蛤，螺蛳**等                                                                                                                                                                                                   | 即使是养殖的贝类也不吃人工饲料，所以它们的营养状况与野生的同类相似                                                                   |
| 海藻     | **海带，大型褐藻，海苔，裙带菜**                                                                                                                                                                                              | 膳食碘的最佳来源                                                                                            |
| 鸡蛋     | 牧场养殖，硬壳，有机认证或者鸭蛋，鹌鹑蛋，鸵鸟蛋，野鸡，火鸡蛋等                                                                                                                                                                                | 超级食物的一种                                                                                             |
| 蔬菜     | 抗氧化能力很高的蔬菜有**甜菜、西蓝花、抱子甘蓝、胡萝卜、花菜、茄子、大蒜、羽衣甘蓝、洋葱、红色甜椒、菠菜和黄西葫芦**，煮熟了分解了天然毒素再吃                                                                                                                                       | 蔬菜含有大量抗氧化剂、类黄酮、类胡萝卜素等植物营养素,能提升代谢、免疫和细胞功能。它们有助于保护大脑和身体免受衰老和氧化应激的破坏,还能帮你在肠道菌群里培养出有益健康的细菌              |
| 水果     | 高抗氧化剂低血糖的水果有浆果（黑莓、蓝莓、树莓和草莓）、柠檬、青柠和核果(樱桃、桃子、杏子），牛油果                                                                                                                                                              | 本地生长的、当季的新鲜水果是最优选择,它们一般含有相对较高的抗氧化剂和较低的血糖指数                                                          |
| 坚果     | 一定要选择生的或者干烤的坚果，**澳洲坚果酱**和**椰子黄油，核桃**                                                                                                                                                                            | 含有蛋白质、脂肪酸、酶、抗氧化剂、植物营养素和丰富的维生素及矿物质                                                                   |
| 乳制品    | 生的、发酵的、未经高温消毒的、不加糖的、高脂肪的、低碳水化合物的、有机的才称得上是“黄金”乳制品,包括:**酥油、黄油、全脂奶油、茅屋芝士、奶油芝士,以及来自牧场饲养或草饲动物的有机认证的全脂牛奶或生牛乳**。你也可以吃有机发酵乳制品,包括**发酵酪乳、全脂希腊酸奶、开菲尔酸奶、生乳酪、陈年干酪和全脂酸奶油**                                                    | 发酵乳制品可以被归为“超级食物”,因为它们富含一切需要的营养成分,还具有强大的抗炎和抗氧化特性。发酵产品本身虽然是含有碳水化合物和蛋白质的,但发酵过程还能防止我们出现乳糖和酪蛋白不耐受        |
| 黑巧克力   | 要选购那种**可可含量至少70%的**,避开许多号称是黑巧克力,但实际上可可含ᰁ不足45%的产品                                                                                                                                                                | 高可可含量的原豆精制黑巧克力富含抗氧化剂(多酚、黄酮醇、儿茶素)、多种植物营养素,以及丰富的矿物质,诸如铁、铬、铜、镁和锰。可可豆的抗氧化值(ORAC)是极高的——比超级食物里的明星巴西莓和蓝莓还高 |
| 饮料和水   | 在每天摄入足够多的水的基础上,你还可以喝**不加糖的花草茶**或含咖啡因的茶、咖啡(加奶油没问题,但尽量要少加糖),以及经历自然发酵变甜的自制**康普茶**或者用**苏打水**来代替这种饮料(三份苏打水对应一份康普茶)                                                                                                   |                                                                                                     |
| 超级食物   | **器官**（肝脏，大脑，心脏，肾脏，尾骨，睾丸，胃，舌，胰脏），**带骨的肉块**（胶原蛋白），**凝胶状的骨头汤**，发酵和发芽食品（从**苹果醋、生奶酪或陈年干酪、开菲尔酸奶、韩国泡菜、康普茶、生牛奶、味噌、纳豆、橄榄、酸黄瓜、德国酸菜、丹贝和全脂酸奶**里选。这些食物都含有活菌,可以滋养健康的肠道细菌。有些发酵食物,包括**葡萄酒、啤酒、酸面包和可可豆**,虽然不含活的益生菌,但还是能带来许多健康益处） | 从头吃到尾，营养全面均衡                                                                                        |
